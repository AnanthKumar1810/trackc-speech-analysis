# Submission packaging

The refreshed public dataset archive is `TrackC_Public_Dataset_v2_2026-10-15.zip`
in the parent `outputs/` folder. It contains the permitted archival source
speech, 273 generated WAVs, exact digital-edit labels, MFA word-alignment
outputs, features, code, the evaluator dashboard and the updated three-page
technical report. It intentionally omits the 22 private human recordings and
their original files.

`TrackC_Code_Repo_2026-10-15.zip` in the parent `outputs/` folder is a small code bundle
containing source, metadata, dashboard and report. Binary audio,
large features and original source media belong in the separate dataset ZIP.
Create a new **public** GitHub repository, extract the code bundle, and use
GitHub Desktop to add and publish the extracted folder. Upload the public dataset ZIP to a public
download location (for example Google Drive with "anyone with the link can
view"). Put that dataset URL in the repository README and submit both links.

Check `RIGHTS.md` and `PROJECT_STATUS.md` before publication. The private
participant audio has no documented redistribution consent. Do not publish it.
The user is handling the video separately.
