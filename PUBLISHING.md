# Publishing and dataset access

This Git repository contains the code and documentation. Audio and derived feature arrays are distributed separately because they make the dataset large. The public dataset archive is assembled locally as `TrackC_Public_Submission_2026-10-14.zip`; publish that archive only through a download location permitted by the hackathon and the source rights listed in `RIGHTS.md`. Add the verified public download URL here and in `README.md` after it is uploaded.

The archive excludes the private participant recordings and their original filenames. Do not add `human_pilot/`, `real_evaluation/`, local caches, browser profiles, or raw participant media to this Git repository. The current participant recordings have no documented public redistribution consent.

Before submitting, verify the repository URL and dataset URL, check that the default branch and downloadable archive are public, and include the video link supplied by the project owner. Do not describe synthetic-edit results as natural-speech accuracy.
