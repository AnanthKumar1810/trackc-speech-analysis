Interpretation & limitations

How to read these results

The 62.7% test F1 uses a paired classifier to keep only the predicted edit type under the benchmark’s one-edit-per-clip setup. The acoustic localizer alone scores 49.8% F1. Both are measured on digitally altered archival speech—not natural-speech accuracy, a human rating, or a validated quality score.

The type gate reduces incorrect cross-type candidates in this controlled benchmark. Natural speech can contain several simultaneous issues, so the gate is not applied to new uploaded recordings. Human-verified transcripts, boundaries, flaw intervals and independent ratings are still needed.
